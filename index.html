One feature, every layer

CoinPrime

Regulation required blocking sign-ups by country — including people arriving through Google, who skip the registration form entirely. I built the fix across the whole stack:

Interface

A country step in the Google sign-up flow, and a loader-first callback screen that never flashes an error before success.

Proxy

Next.js forwards API calls on the same origin. The refresh token lives in an httpOnly cookie, the access token only in memory, and OAuth state is verified idempotently so a repeated callback can't fail the sign-in.

API

A pending Google sign-up holds a single-use, encrypted ticket in Redis until the country is known. Domain errors come back as a typed result the UI can render, not a generic failure.

Policy

Country restrictions are enforced on the server for every sign-up path — the UI step is for the user, not for security.
